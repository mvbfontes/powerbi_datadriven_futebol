# ⚽ Desafio Data Driven — Campeonato Brasileiro de Futebol

## 📝 Descrição

Projeto desenvolvido para o desafio da comunidade Data Driven, com foco na análise histórica do Campeonato Brasileiro de Futebol. O relatório explora resultados, classificação, artilharia, desempenho dos clubes e indicadores disciplinares.

## 🗄️ Base de dados

- **Origem:** [Kaggle — Campeonato Brasileiro de Futebol](https://www.kaggle.com/datasets/adaoduque/campeonato-brasileiro-de-futebol)
- **Descrição:** dados de partidas do Campeonato Brasileiro, incluindo placares, clubes, estádios, técnicos, gols e cartões.

## 🔎 Análises disponíveis

- Visão geral do campeonato por edição
- Tabela completa e classificação
- Artilharia e desempenho dos jogadores
- Performance por clube
- Análise histórica e disciplinar
